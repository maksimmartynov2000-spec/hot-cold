# Hot or Cold

Игра «угадай число»: после каждой попытки подсказка — горячо или холодно.
Работает в браузере и ставится на телефон как приложение (PWA).

Режимы: Тренировка, игра вдвоём на одном телефоне, Приключение (50 миров
соперников-ботов), Испытание (раунды подряд, таблица лучших) и партии с
друзьями из «Друзей» на разных телефонах. Игры со случайными соперниками,
рейтинга и лиг нет (миграция 062). За любую игру — сундук дня, серия дней
и сезонный путь; по выходным — «Испытание выходных». Монеты 🪙 и кристаллы 💎
тратятся в магазине на иконки, рамки, фоны, титулы, фразы, питомцев с
обликами и аурами, градусники и эффекты победы (начисляет и списывает только
база).

## Как устроено

- **Игра** — `index.html` (разметка), `styles.css` и скрипты в `js/`:
  переводы, игра без сети, всё через сервер, запуск. Сборки нет: обычные скрипты
  подключаются по порядку. Сайт отдаёт GitHub Pages прямо из ветки `main`.
- **Сервер** — Supabase (PostgreSQL). Вся логика с сервером — в функциях базы:
  они проверяют PIN игрока и сами решают, что можно. Таблицы снаружи закрыты.
  В игре лежит только публичный ключ, служебного ключа нет нигде.
- **Уведомления** — функция Supabase в `push/`, ставится вручную по
  `push/README.md`.

## Файлы

| Где | Что |
|---|---|
| `index.html` | разметка: экраны и окна |
| `styles.css` | стили |
| `js/i18n.js` | переводы на 4 языка |
| `js/game.js` | игра без сети: правила, дуэль, бонусы, бот, разбор |
| `js/online.js` | всё через Supabase: аккаунт, друзья, партии с ними, задания, Испытание |
| `js/pass.js` | сундук дня, серия, сезонный путь, «Испытание выходных», рамки и титулы |
| `js/shop.js` | магазин: витрина, кошелёк, покупка, «+монеты» после игры |
| `js/pets.js`, `js/pet-art.js` | питомцы: карточка в меню, их экран, питомец в партии; ауры (SVG собирает `tools/pets/pets.py`) |
| `icons/pets/` | картинки питомцев: по шесть эмоций и шесть обликов у каждого |
| `js/main.js` | запуск |
| `vendor/` | чужие библиотеки: supabase-js 2.118.0 и QR-код |
| `sw.js`, `manifest.webmanifest`, `icon-*.png` | офлайн-работа и установка на телефон |
| `supabase/migrations/` | изменения базы, пронумерованы в порядке применения |
| `supabase/checks/` | проверка, что миграция применилась: только читает базу |
| `supabase/admin/` | разовые служебные скрипты |
| `push/` | отправитель уведомлений и страница создания ключей |
| `tests/db/` | проверки базы на настоящем PostgreSQL |
| `tests/` | проверки игры в браузере |

Файлы в корне сайта (`index.html`, `sw.js`, манифест, иконки) и
`push/keys.html` не переносить: их адреса знают браузеры игроков. Новый
файл игры — вписать в `CORE` в `sw.js` и поднять там версию кеша, иначе без
сети игра не откроется (это проверяет `npm test`).

## Как менять базу

Миграция из `supabase/migrations/` → SQL Editor в Supabase → Run, затем
проверка с тем же номером из `supabase/checks/`. Подробно — в
`supabase/README.md`.

## Как проверить

```bash
sh tests/db/run.sh    # база: собирается с нуля и прогоняет все сценарии
cd tests && npm install
npm test              # игра в браузере с заглушкой вместо сервера
npm run layout        # вёрстка на разных размерах экрана
npm run offline       # работа без интернета
npm run e2e           # игра в браузере против настоящей базы
```

Подробнее — в `tests/README.md`.
