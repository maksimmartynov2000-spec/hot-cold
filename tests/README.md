# Проверки

Браузерные проверки на Playwright. Ловят то, что не видно в коде: наложения
элементов, нечитаемый текст, неработающие кнопки, сломанные переводы.

## Как запустить

```bash
cd tests
npm install
npm test          # основные проверки (33 шт.)
npm run offline   # проверка работы без интернета
```

Тесты открывают `index.html` напрямую из файла и подменяют Supabase заглушкой,
поэтому интернет и живая база не нужны. Исключение — `offline.js`: он поднимает
локальный сервер, потому что service worker не работает с `file://`.

Что уже поймали эти проверки: переключатель языка, наезжавший на строку статуса
и блокировавший кнопку; чёрный текст на тёмном фоне в окне подтверждения;
очистку полей формы при показе ошибки; повторное начисление очков за уже
угаданное число.
