# Приключение: исходники героев миров 6–50

Игра этих файлов не грузит. Из них собираются `js/adventure.js` (список
`ADV_HEROES` и сдвиги силы `ADV_BRAIN_SHIFT`) и тексты `js/adv-<язык>.js`.
Герои идут партиями по 10 миров (100 героев). Номер героя `n` = 50 + индекс.

| Файл | Что внутри |
|---|---|
| `specN.py` | правила героев партии N: условие × действие, черты (`pick`, `first`…) |
| `tN_ru.py`, `tN_en.py`, `tN_fr.py`, `tN_de.py` | имя, правило, реплики на 4 языках |
| `levelsN.json` | сила: сдвиг мира и поправка героя, подобраны симуляцией |
| `activateN.py` | включает миры партии в `ADV_WORLDS` (числа, цвет, бонус мира, правило мира), с `art` — ещё и портреты |
| `portraits/` | подсказки для Gemini, нарезка листов, готовые `icons/adv-NNN.webp` |
| `balance/` | симуляция «среднего игрока» и подбор силы |

## Собрать

Из корня репозитория:

```
python3 -I tools/adventure/build.py . 2        # правила партий 1–2, тексты — где готовы все 4 языка
python3 -I tools/adventure/check.py 3 ru       # проверка текстов партии 3
```

В игру попадают только миры из `ADV_WORLDS`, поэтому партию собирают в файлы,
когда её мир готов включать, — иначе тексты зря грузятся у игроков.

## Портреты

1. Подсказки листов — `portraits/promptsN.txt` (5 листов по 20 героев). В Gemini к каждому
   листу прикладывают образец стиля `portraits/style-ref.jpg`.
2. Каждый лист режется на клетки: `python3 -I tools/adventure/portraits/cutsheet.py лист.jpg cut 1a`
   (лист 1, вариант a). Вариантов листа может быть несколько.
3. Лучший вариант каждой клетки и сияние боссам:
   `python3 -I tools/adventure/portraits/finish.py N cut icons "aaaa…/…"`.
4. Миры с портретами включает `python3 -I tools/adventure/activateN.py . art`.

Герои — живые: звери, фэнтези, космос, мифы. Игрушки, сладости, посуда и прочие
вещи с глазками — слишком «для малышей», их больше не заводим. 106 таких героев
миров 6–35 заменены живыми (`portraits/heroesR.py`, подсказки `promptsR.txt`,
выбор вариантов — `finishR.py`); правило и сила у замены — прежние.
Досъёмка (робокраб, протей и три героя мира 5 вместо метеорита, кометы и
чёрной дыры) — `promptsR2.txt`.

## Сила

Цель на «Нормально» для «среднего игрока»: в первом мире волны обычные герои —
около 52–58% побед, к пятому — 24–30%, боссы ниже; от волны к волне на 2 п.п. ниже.

```
cp -r . /tmp/game                                   # копия игры для симуляции
python3 -I tools/adventure/build.py /tmp/game 3      # правила и тексты партии 3 — только в копию
python3 -I tools/adventure/activate2.py /tmp/game    # миры 16–25, если ещё не включены
python3 -I tools/adventure/activate3.py /tmp/game    # миры 26–35
OUT=/tmp/adv-balance DAMP=0.6 python3 -I tools/adventure/balance/calib.py 1 160 25 /tmp/game
python3 -I tools/adventure/mklevels.py /tmp/adv-balance/calib_25.json tools/adventure/levels3.json 25
```

Если у партии уже есть `levelsN.json`, подбор начинается с него — так пересчитывают
силу после новых бонусов или правил миров. Состояние подбора — `$OUT/calib_W0.json`:
чтобы начать заново, его удаляют.

`calib.py` повторяют, пока среднее отклонение не сравняется с шумом
(около 3 п.п. при 200 играх на героя). Соперник умнее 0,98 не становится: если
герой и на пределе слишком лёгкий, меняют его правило, а не силу.
